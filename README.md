## Overview

MultiMC is the original multi-instance Minecraft launcher, allowing players and developers to manage completely independent Minecraft installations each with their own mods, saves, and settings. It pioneered per-instance Java arguments, modpack zip import, and was the inspiration for the modern GDLauncher and Prism Launcher community forks.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **MultiMC** delivers the features you need in a clean, intuitive package.

> Official website: [multimc.org](https://multimc.org)

## Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Instance** | Run completely separate Minecraft instances isolated from each other |
| **Modpack Import** | Import modpack zip files and auto-extract into a new instance |
| **Java Configuration** | Per-instance Java arguments and memory allocation configuration |
| **Lightweight** | Minimal resource footprint — does not run as a background service |
